# 경사하강법 학습률 실험 보고서

## 실험 목적

경사하강법에서 학습률 `lr`을 작게 또는 크게 설정했을 때, 최솟값에 얼마나 빨리 도달하는지 확인한다.

이번 실험 함수는 다음과 같다.

```text
f(x) = sum(x^2 + x)
f'(x) = 2x + 1
```

각 차원에서 최솟값은 다음 조건으로 구한다.

```text
2x + 1 = 0
x = -0.5
```

따라서 목표 지점은 `+0.5`가 아니라 `-0.5`이다.

## 관찰 포인트

학습률이 너무 작으면 한 번에 조금씩만 이동하므로 수렴이 느리다.

```text
lr = 0.01
```

이 경우 안정적이지만 많은 step이 필요하다.

학습률이 적절히 크면 최솟값에 빠르게 가까워진다.

```text
lr = 0.1
lr = 0.3
```

이 경우 이동 폭이 충분해서 빠르게 `-0.5` 근처로 접근한다.

이번 함수에서는 `lr = 0.5`가 특수하게 매우 빠르게 최솟값에 도달한다.

업데이트 식은 다음과 같다.

```text
x_new = x - lr * (2x + 1)
```

여기서 `lr = 0.5`를 넣으면:

```text
x_new = x - 0.5 * (2x + 1)
      = x - x - 0.5
      = -0.5
```

즉 이 2차 함수에서는 어느 위치에서 시작해도 한 번에 `-0.5`로 이동한다.

반대로 `lr = 1.0`이면:

```text
x_new = x - (2x + 1)
      = -x - 1
```

예를 들어 `x = 1`에서 시작하면:

```text
1 -> -2 -> 1 -> -2 -> ...
```

최솟값에 수렴하지 않고 양쪽을 반복해서 왔다 갔다 한다.

## 결론

학습률 `lr`은 작을수록 안정적이지만 느리고, 클수록 빠를 수 있지만 너무 크면 최솟값을 지나쳐 수렴하지 못한다.

이번 함수 `f(x)=x^2+x`에서는 최소점이 `x=-0.5`이고, `lr=0.5`는 수학적으로 한 번에 최소점으로 가는 특수한 값이다. 하지만 일반적인 함수나 실제 신경망 학습에서는 이런 값이 항상 존재하지 않으므로, 너무 큰 학습률은 발산이나 진동을 만들 수 있다.
